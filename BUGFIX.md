## Что не работало по UI

Селект "Выбрать услугу" и инпут "Кол-во" не реагировали на ввод, кнопка "Добавить" заблокирована. При фиксе кнопки не работало отображение выбранных услуг.

## Причины

`selectedServices`, `selectedServiceId` и `quantity` без state, обновление переменных через мутации. Как итог - value в input/select не изменялось, кнопка не обрабатывала изменение на disabled. `selectedServices` и вовсе объявлялся как пустой массив и при каждом ререндере создавался заново пустым.

## Решение

Использование `useState` с обновлением состояния через соответствующий `setState`. Плюс push/splice и existing.quantity += меняли массив через мутацию, и даже если бы state был, React бы не увидел изменение без нового массива/элементов (нужна иммутабельность через spread/map/filter).

## Другие баги

- `const existing = selectedServices.find((item) => item.service === service);` - поиск дубликата не по id, а по объекту целиком
- `totalPrice` - добавлена мемоизация с зависимостью от выбранных услуг (можно было обойтись без мемоизации на малом объеме данных, но может давать выигрыш при оптимизации компонента)
- в onChange для инпута "Кол-во" можно ввести значения выходящие за границы min/max. Этот баг скорее продуктовый, и вариантов решения много, исправлять не стала для избежания лишних вопросов. Как вариант решения - `Math.min(QUANTITY_MAX, Math.max(QUANTITY_MIN, value))`
